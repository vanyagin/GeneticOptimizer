Как записать функцию

Переменные обозначаются x0, x1, x2, … — нумерация начинается с нуля и идёт без пропусков.

Операторы + - * /, степень ^, скобки ( )
Функции sin cos tan asin acos atan sinh cosh tanh exp log (нат.) log2 log10 sqrt abs sign min max sum avg
Константы _pi ≈ 3.14159, _e ≈ 2.71828
Разделитель дробная часть — через точку: 0.5, 3.14

Примеры:

  • (x0^2 + x1 - 11)^2 + (x0 + x1^2 - 7)^2 — функция Химмельблау
  • 100*(x1 - x0^2)^2 + (1 - x0)^2 — функция Розенброка
  • x0^2 + x1^2 + x2^2 — сфера (3 переменные)

По умолчанию каждая переменная ищется в диапазоне [-5, 5]. Чтобы задать свои границы, включите «Указать диапазоны переменных».

Каким должен быть exe-файл

Программа вызывает ваш .exe для каждой точки, которую проверяет алгоритм. Обмен данными идёт через текстовые файлы рядом с программой.

  1. Вход. Перед запуском координаты точки записываются в файл data2.txt — по одному числу на строке. Строк ровно столько, сколько указано в поле «Число аргументов».
  2. Вычисление. Ваш .exe читает эти числа, считает значение целевой функции.
  3. Выход. Результат — одно число — записывается в первую строку файла res.txt. Разделитель дробной части — точка или запятая (запятая будет автоматически заменена на точку).
Файл входаdata2.txt — N строк, по одному числу
Файл выходаres.txt — одно число в первой строке
Аргументыкомандной строки не принимает — данные только через файлы
Рабочая папкафайлы читаются и пишутся в каталоге программы
Диапазонпоиск по каждому аргументу фиксирован: [-5, 5]

Схема работы (псевдокод):

x = read_lines("data2.txt")     # N чисел, по строке
y = f(x)                        # ваша целевая функция
write("res.txt", y)             # одно число
