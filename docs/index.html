Онлайн-демонстрация: все вычисления идут прямо в вашем браузере, сервер не нужен. Версия с загрузкой собственного .exe и C++-ядром доступна в десктопном приложении (см. репозиторий проекта).

Как записать функцию

Переменные обозначаются x0, x1, x2, … — нумерация начинается с нуля и идёт без пропусков.

Операторы + - * /, степень ^, скобки ( )
Функции sin cos tan asin acos atan sinh cosh tanh exp log (нат.) log2 log10 sqrt abs sign min max sum avg
Константы _pi ≈ 3.14159, _e ≈ 2.71828
Разделитель дробная часть — через точку: 0.5, 3.14

Примеры:

  • (x0^2 + x1 - 11)^2 + (x0 + x1^2 - 7)^2 — функция Химмельблау
  • 100*(x1 - x0^2)^2 + (1 - x0)^2 — функция Розенброка
  • x0^2 + x1^2 + x2^2 — сфера (3 переменные)

По умолчанию каждая переменная ищется в диапазоне [-5, 5]. Чтобы задать свои границы, включите «Указать диапазоны переменных».
