ОПТИМИЗАТОР ФУНКЦИЙ — установщик и портативная версия
=====================================================

Что это
-------
Локальная веб-версия оптимизатора (дифференциальная эволюция jDE
и алгоритм оптимизации китов). Запускается в браузере на любом компьютере
с Windows 10/11 (x64). Интернет на компьютере комиссии НЕ нужен — Python,
Flask и Plotly уже вложены внутрь.

Как собрать (один раз, на вашей машине с интернетом)
----------------------------------------------------
1. Запустите файл  build.bat  (двойной клик).
2. Скрипт сам:
   - скачает встроенный Python с python.org (~10 МБ);
   - настроит окружение;
   - соберёт установщик GeneticOptimizer-Setup.exe (если установлен NSIS);
   - соберёт портативную версию GeneticOptimizer-portable.zip.
3. Готовые файлы появятся рядом с build.bat.

NSIS (для .exe-установщика) — бесплатный, ставится в один клик с
https://nsis.sourceforge.io . Если его нет, build.bat всё равно соберёт
портативный zip — его достаточно для запуска.

Что отдать комиссии
-------------------
Вариант А (установщик):
   GeneticOptimizer-Setup.exe  — запустить, пройти мастер. Установка идёт
   в профиль пользователя (без прав администратора), создаются ярлыки в меню
   «Пуск» и на рабочем столе. Запуск — ярлык «Оптимизатор функций».

Вариант Б (портативный, если хостинг недоступен):
   GeneticOptimizer-portable.zip — распаковать в любую папку и запустить
   файл «run.bat». Установка не нужна.

В обоих случаях откроется консольное окно (его не закрывать, пока работаете)
и автоматически — браузер со страницей оптимизатора по адресу
http://127.0.0.1:5000 . Чтобы выйти — закрыть консольное окно.

Состав папки payload
--------------------
  app.py               — веб-сервер (Flask + waitress)
  GeneticAlgoritm.exe  — ядро оптимизатора (C++)
  muparser.dll         — библиотека разбора формул
  pylib\               — вложенные Python-библиотеки (Flask, Plotly offline и др.)
  static\, templates\  — веб-интерфейс
  app.ico              — иконка
  run.bat        — запуск портативной версии
  python\              — встроенный Python (появляется после build.bat)

Требования
----------
  Windows 10/11 64-бит. Для сборки — доступ в интернет (только на этапе build.bat).
